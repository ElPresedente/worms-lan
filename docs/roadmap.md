# План разработки Office Worms

Зафиксирован 24 октября 2026. Этапы определяют результат и критерии готовности без календарных обещаний.
Границы ответственности: [архитектура](architecture.md).

## Правила ведения

- `[x]` — реализовано и проверено; `[ ]` — работа или проверка ещё не завершена.
- Этап закрывается после выполнения всех критериев. Вместе с кодом обновляются ROADMAP и документация.
- Будущие сценарии приёмки не означают, что соответствующие тесты уже существуют.
- Новый функционал ядра сопровождается управлением и визуальной проверкой в клиенте.
- Новое оружие и несколько червей идут после MVP.

## Порядок интеграции

| Веха | Работы | Критерий завершения |
| --- | --- | --- |
| M0. Доступный полигон — готов | C0 завершён | Страница открывается на машине пользователя; видны выстрел, воронка, HP и смена очереди |
| M1. Локальная механика MVP — готова | G1/G2 + C1 | Два игрока могут двигаться, прыгать, стрелять и завершить матч; падение и отбрасывание видны в клиенте |
| M2. Первая сетевая партия | P0/P1 + S0/S1 + C2 | Два браузера играют одну партию, симуляцию ведёт только сервер |
| M3. Игра между рабочими задачами | P2 + S2 + C3 | Скрытие вкладки не останавливает матч; переподключение восстанавливает состояние без повторного действия |
| M4. Игра в редакторе | V0–V2 + C4; требуется M3 | Общий клиент работает в webview; уведомления об очереди соблюдают минимальный интервал |
| M5. LAN MVP | G3 + P3 + S3 + C5 + V3; требуются M1–M4 | Два компьютера в LAN проходят полную партию в VS Code |

M1 завершена. В M2 готовы P0/P1; S0 принят пользователем 24 октября 2026, включая TCP-проверку. Далее S1 + C2.
Каркас webview можно проверить с LocalSession до появления сети; продуктовая партия использует сервер.

## Приёмка LAN MVP

- [ ] Два игрока, по одному червю; ходьба, прыжок, базука, разрушение, урон, победа/ничья.
- [ ] Создание комнаты и подключение второго игрока по LAN-адресу.
- [ ] Свободное ожидание до «Начать ход», затем активный таймер по умолчанию 60 секунд.
- [ ] Сервер продолжает активный ход и полёт при скрытом или закрытом клиенте.
- [ ] Возвращение в матч восстанавливает карту, HP, очередь и таймер.
- [ ] Повтор команды не повторяет выстрел; управление чужим червём запрещено.
- [ ] Уведомления работают при скрытой/закрытой игровой панели, пока VS Code и подключённое расширение активны.
- [ ] Полная партия на двух машинах с обрывом связи, повторным входом и завершением матча.
- [ ] Инструкции установки, запуска и диагностики проверены по шагам.

## Решения перед реализацией

- P0 завершён: [WebSocket /ws, версия 1, лимиты, серверная идентичность и асинхронные подтверждения](../packages/protocol/SPEC.md). P1 реализует DTO/валидаторы; подключение к сети — S0/S1/C2.
- P2/S2: срок сохранения места и политика отключившегося игрока. Предложение:
  waiting остаётся без таймера, начатый ход завершается обычным таймаутом; решение ещё нужно принять.
- P2: сначала полные снимки с ограниченной частотой; дельты карты только после измерений.
- S2/S3: для MVP допустимо хранение в памяти с явно описанной потерей партии при рестарте.
- V2: поведение уведомлений при повторном подключении и объединение событий за минимальный интервал.

После MVP: discovery сервера, сохранение на диск, реплеи, новые карты, команды и оружие.
