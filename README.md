# Office Worms

Пошаговая игра в духе Worms для локальной сети и вкладки VS Code.
Сейчас доступны независимое ядро и браузерный клиент для визуальной проверки механики.

## Быстрый запуск

Node.js 22.16+ и npm 10+.

```sh
npm ci
npm run dev
```

Открыть **http://127.0.0.1:4173**. Если порт занят: `npm run dev -- --port 4174`.

Нажать «Начать ход», выбрать угол и силу, затем «Огонь» или Space.
После взрыва и завершения падений очередь перейдёт второму игроку.
Можно прицеливаться кликом по полю. Ходьба: A/D или ←/→; прыжок: W или ↑. Есть кнопки управления и карта «Полоса препятствий».

Dev-сервер автоматически пересобирает изменения в исходниках ядра/клиента и перезагружает страницу.
**Перезагрузка создаёт новый матч.** Изменения package.json/tsconfig требуют перезапуска команды.

Если среда запрещает создание workspace-ссылок (EPERM symlink), используйте
`npm ci --workspaces=false`. Текущие сборка, тесты и браузерный запуск поддерживают этот режим:
TypeScript разрешает типы ядра через paths, браузер — через import map.

## Команды

| Команда | Что делает |
| --- | --- |
| `npm run dev` | Собирает ядро и клиент, запускает localhost, следит за исходниками и перезагружает браузер |
| `npm run build` | Собирает ядро и самодостаточный статический клиент в `packages/client/dist` |
| `npm run server` | Собирает и запускает игровой сервер S0 на 127.0.0.1:4180 |
| `npm run test:server:tcp` | Проверяет сервер через TCP в обычном локальном терминале |
| `npm run preview` | Раздаёт уже собранный клиент без слежения за файлами |
| `npm test` | Собирает четыре пакета, проверяет ядро, клиент, протокол и сервер (включая типы) |
| `npm run demo` | Показывает один выстрел и события ядра в терминале |

HTTP-сервер использует только встроенные модули Node.js, слушает 127.0.0.1.
Это сервер статических файлов для разработки, а не сетевой игровой сервер.
Двойной клик по index.html через file:// не поддерживается: нужен HTTP.

## Что уже работает

- Два игрока за одним экраном, по одному червю; ожидание, начало хода, 60-секундный таймер и пропуск.
- Ядро G1: ходьба, прыжок, ступеньки, столкновения с рельефом и живыми червями.
- G2: отбрасывание взрывом, затухание скорости, урон от падения и ожидание остановки тел.
- Базука с углом/силой, гравитация и ветер; взрыв, воронка, урон, падение, победа и ничья.
- Canvas-клиент: карта, черви, HP, активная команда, снаряд, след и эффект взрыва.
- Диагностика: пауза, один тик, замедление, сетка, контуры тел, журнал событий и просмотр снимка.
- Четыре тестовые карты и настройка ветра при перезапуске.

Локальная симуляция намеренно останавливается в скрытой вкладке. При зависании кадра
догоняет не более 250 мс: это отладочные часы, не авторитетные часы будущего сервера.
Сеть, сохранение партий и расширение VS Code пока не реализованы.

## Структура и документация

Один репозиторий с независимыми npm workspace-пакетами.

| Пакет | Назначение | Состояние |
| --- | --- | --- |
| `packages/game-core` | Правила и симуляция матча | Первый рабочий срез |
| `packages/client` | Переносимый DOM/Canvas-клиент и браузерный запуск | Работает локально |
| `packages/protocol` | Версионируемый сетевой контракт | P0/P1: спецификация, DTO, runtime-валидаторы и тесты |
| `packages/server` | Авторитетный LAN-сервер, комнаты, подключения | S0 готов и принят; комнаты — S1 |
| `packages/vscode-extension` | Webview, уведомления и настройки VS Code | Запланирован |
