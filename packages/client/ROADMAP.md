# client — этапы разработки

Общий порядок: [план проекта](../../docs/roadmap.md). Клиент показывает состояние и отправляет команды;
правила остаются в ядре/на сервере.

## C0. Браузерный полигон — готов

- [x] Canvas-карта, черви, HP, прицел, снаряд, разрушения и эффекты событий.
- [x] LocalSession, начало/пропуск хода, угол/сила/выстрел и две тестовые карты.
- [x] Пауза, один тик, замедление, сетка, контуры, журнал и инспектор.
- [x] Сборка, dev/preview и автоматические проверки локальной сессии.
- [x] Подтверждено открытие страницы на машине пользователя после npm run dev.
- [x] В браузере проверены выстрел → воронка/урон → смена очереди, пауза/шаг и переключение карты.

Визуальная приёмка пройдена: 24 октября 2026 пользователь подтвердил, что клиент отлично работает.

## C1. Управление механикой MVP — готов

Зависит от C0; совместно с G1/G2.

- [x] Ходьба/прыжок, подсказки клавиш, блокировка управления по фазе/очереди.
- [x] Отпускание управления при потере фокуса, скрытии вкладки и окончании хода.
- [x] Отображение отбрасывания, приземления и урона от падения по данным ядра.
- [x] Диагностическая карта со стенами/уступами; проверка прицела и координат после resize.

Автопроверки 24 октября 2026: 41 тест ядра и клиента проходят; полоса проходится командами.
Координаты после resize проверены тестом; визуальная приёмка части G1 подтверждена пользователем 24 октября 2026.
- [x] Ручная приёмка в браузере: ходьба/прыжок, потеря фокуса, прицел после resize — подтверждена пользователем 24 октября 2026.

G2 подключён: подписи урона/приземления, векторы скорости и карта «Высота и падения».
Автопроверки: 50 тестов проходят, включая однократный урон при спуске с высокого уступа.
- [x] Визуальная приёмка части G2: отбрасывание, падение, урон и очередь после стабилизации — подтверждена пользователем 24 октября 2026. C1 принят.

Готово: M1 проходится клавиатурой и мышью без ручного изменения состояния.

## C2. Сетевой адаптер

P1 завершён: [DTO/валидаторы](../protocol/README.md) готовы; сетевой адаптер зависит от S1.
[Контракт P0](../protocol/SPEC.md) определяет Promise-подтверждения,
pending-команды и исход unknown; синхронный GameSession нужно пересмотреть в C2.

- [ ] Добавить асинхронные подтверждения, ожидающие команды, отказы и состояние соединения.
- [ ] Реализовать RemoteSession через protocol; сохранить LocalSession для разработки.
- [ ] Добавить адрес сервера, создание/вход в комнату, ожидание второго игрока и запуск.
- [ ] Отправлять команды серверу; показывать серверные снимки/таймер без локальной симуляции.
- [ ] Блокировать опасные повторы до подтверждения и показывать понятные отказы.

Готово: два браузера играют один матч и показывают одинаковое подтверждённое состояние.

## C3. Восстановление соединения

Зависит от P2/S2.

- [ ] Состояния подключения, потери связи, повторной попытки и окончательного отказа.
- [ ] Восстановление сессии/снимка с различением нового матча и обновления текущего.
- [ ] Обработка пропусков/повторов обновлений без повторного проигрывания эффектов.
- [ ] Возврат из скрытой вкладки с актуальным серверным временем.

Готово: обрыв во время полёта и возврат в свою очередь не повторяют выстрел и не оставляют старую карту.
