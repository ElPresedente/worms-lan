# game-core — этапы разработки

Общий порядок: [план проекта](../../docs/roadmap.md). Ответственность — правила и симуляция, без UI и I/O.

## G0. Базовый цикл — готов

- [x] Независимые createGame/dispatch/step, фиксированный шаг 1/60 секунды, JSON-состояние и события.
- [x] Два игрока, ожидание/начало/таймер/пропуск хода, проверка очереди и фазы.
- [x] Базука, ветер, взрыв, разрушение, урон, вертикальное падение, победа/ничья.
- [x] Автоматические проверки, неизменяемость входов и JSON round-trip.

Подтверждение: существующие тесты game-core и консольный пример. Это первый срез, не полный MVP.

## G1. Перемещение и прыжок — готов

Зависит от G0; визуальная приёмка совместно с C1.

- [x] Определить команды начала/остановки движения и прыжка; необходимое состояние управления хранить в GameState.
- [x] Реализовать ходьбу, блокировку стенами/потолком, прыжок и приземление.
- [x] Определить допустимые ступеньки/уклоны и столкновения между червями; описать правила.
- [x] Разрешать движение только активному живому червю; сбрасывать управление при окончании хода.
- [x] Проверить стену, край платформы, узкий проход, повтор прыжка в воздухе и таймаут во время движения.

Готово: червь проходит тестовую полосу в клиенте без проникновения в землю;
одинаковые команды/тики дают одинаковое состояние в проверенной среде.

Автопроверка 24 октября 2026: `npm test` — 35 тестов, все проходят (9 новых тестов G1).
- [x] Визуальная приёмка полосы препятствий в клиенте C1 — подтверждена пользователем 24 октября 2026.

## G2. Взрыв, отбрасывание и падения — готов

Зависит от G1; отображается в C1.

- [x] Добавить импульс взрыва, горизонтальную скорость и затухание движения.
- [x] Ввести урон от падения с описанным порогом/формулой без повторного начисления за одно падение.
- [x] Завершать resolving после стабилизации тел; определить защиту от бесконечного разрешения.
- [x] Проверить самоподрыв, разрушение опоры, столкновение отброшенного тела, гибель от падения и одновременную смерть.

Готово: следующий ход начинается после завершения последствий; урон и победа соответствуют событиям.

Автопроверка 24 октября 2026: `npm test` — 50 тестов проходят. Правила описаны в README.

## G3. Стабилизация для LAN MVP

Зависит от G2; согласуется с P1/P2 и S1.

- [ ] Зафиксировать команды, события, единицы измерения и версию состояния.
