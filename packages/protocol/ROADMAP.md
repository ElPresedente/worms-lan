## P1. Контракт первой сетевой партии — готово

Зависит от P0; разблокирует S0/S1 и C2.

- [x] Создать TypeScript-пакет с DTO/валидаторами без платформенных зависимостей.
- [x] Проверять произвольный JSON на обеих границах: типы, числа, диапазоны, строки, массивы и снимки.
- [x] Определить requestId/commandId; отделить игровые отказы от ошибок формата.
- [x] Проверить неверную версию, неизвестный тип, повреждённый снимок и превышение лимитов;
  ошибки парсинга обрабатывать без падения процесса.

Готово: общий контракт и четыре безопасных parse/validate-функции доступны для обеих границ.
Проверено 24 октября 2026: 37 тестов protocol, TypeScript-проверки контрактов и
50 существующих тестов ядра/клиента проходят. Отдельно проверены все примеры P0,
реальные снимки на протяжении матча, UTF-8-размеры, подмена playerId и некорректный JSON.
Подключение проверок к реальному WebSocket выполняется в S0/S1 и C2.
