# vscode-extension — этапы разработки

Статус: только план, реализации/package.json пока нет.
Общий порядок: [план проекта](../../docs/roadmap.md).
Ответственность — редактор, жизненный цикл и уведомления; UI берётся из client.

## V0. Каркас и webview

Раннюю проверку можно выполнить с C0/LocalSession.

- [ ] Пакет расширения, команды открытия/фокусировки, запуск в Extension Development Host.
- [ ] Общий client с webview-bootstrap без копирования renderer/UI.
- [ ] webview.asWebviewUri, localResourceRoots, CSP/nonce и локальные ресурсы без CDN.
- [ ] Повторное открытие и dispose без дублирования панелей/подписок.

Готово: общий клиент работает в VS Code; закрытие/открытие не оставляет старых обработчиков.

## V1. Сетевая партия в редакторе

Зависит от C2/C3/C4, P2 и S2.

- [ ] Адрес сервера в настройках, подключение и восстановление места игрока.
- [ ] Выбрать владельца соединения: расширение или webview. Канал очереди должен работать
  при скрытой/закрытой панели, пока расширение активно и подключено к матчу.
- [ ] Типизированный проверяемый мост с ограниченным набором сообщений.
- [ ] Сессионные секреты хранить средствами расширения, не выводить в журнал.
- [ ] Проверить браузер ↔ VS Code, VS Code ↔ VS Code и восстановление панели по снимку.

Готово: закрытие панели не останавливает матч, повторное открытие показывает актуальные карту/HP/очередь.

## V2. Уведомления о ходе

Зависит от V1; очередь читается из снимка и событий protocol.

- [ ] Включение уведомлений и минимальный интервал между ними.
- [ ] Определить поведение при восстановлении соединения и при уже открытой игре.
- [ ] Исключить дубликаты; перед отложенным показом проверить текущий матч/очередь,
  отменять устаревшие уведомления.
- [ ] Действие открытия игры из уведомления и индикатор очереди в редакторе.
- [ ] Проверить скрытую/закрытую панель, переподключение, быстрые повторы,
  завершение матча до отложенного уведомления.

Готово: игрок узнаёт об очереди без открытого поля; частота соответствует настройке.
Уведомления при закрытом самом VS Code в MVP не требуются.

## V3. Упаковка и приёмка LAN MVP

Зависит от V2/C5/S3/P3.

- [ ] Локально устанавливаемый VSIX с ресурсами клиента.
- [ ] Установка в чистом профиле поддерживаемой версии VS Code;
  документирование минимальной версии и подключения.
- [ ] Проверки CSP, обрыва связи, dispose/деактивации и отсутствия секретов в журнале.
- [ ] M5 на двух компьютерах со сворачиванием игры между ходами и уведомлениями.

Публикация в Marketplace — отдельное действие после MVP, не условие локальной установки.

- [ ] Публикация и обновление после выбора способа распространения.
