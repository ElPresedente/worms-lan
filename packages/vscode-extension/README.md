# Office Worms в VS Code

V0 открывает локальную партию на двоих в одной вкладке редактора. Нужны настольный VS Code
1.103 или новее, Node.js 22.16+ и npm 10+.

## Запуск

1. Откройте корень репозитория в VS Code и выполните `npm ci` в терминале.
2. В разделе Run and Debug выберите **Office Worms: Extension Development Host** и нажмите F5.
   Конфигурация запустит `npm run build` перед открытием нового окна.
3. В новом окне откройте палитру команд и выполните **Office Worms: Open Game**.
   **Office Worms: Focus Game** переводит фокус на существующую панель или создаёт её при первом вызове.

Из терминала в корне проекта тот же режим запускается двумя командами.

```sh
npm run build
code --extensionDevelopmentPath=./packages/vscode-extension
```

## Проверка

1. Нажмите «Начать ход», затем «Огонь». Начальный выстрел разрушает часть карты, снимает HP и передаёт ход.
2. Выполните обе команды из палитры. Они используют одну вкладку **Office Worms**.
3. Закройте вкладку и откройте игру снова. Начнётся новая локальная партия с исходной картой и HP.

Локальное состояние существует до выгрузки webview. VS Code может выгрузить его при переключении вкладок.
Стили и JavaScript загружаются из `dist/client` пакета расширения. Для игры достаточно Extension Development Host.
