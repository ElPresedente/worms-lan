# Office Worms в VS Code

Локальная и сетевая партии открываются в одной вкладке редактора. Нужны настольный VS Code
1.103 или новее, Node.js 22.16+ и npm 10+.

## Запуск

1. Откройте корень репозитория в VS Code и выполните `npm ci` в терминале.
2. В разделе Run and Debug выберите **Office Worms: Extension Development Host** и нажмите F5.
   Конфигурация запустит `npm run build` перед открытием нового окна.
3. В новом окне откройте палитру команд и выполните **Office Worms: Open Local Game**
   или **Office Worms: Open Network Game**.
   **Office Worms: Open Game** и **Office Worms: Focus Game** возвращают в текущий режим.
   При первом вызове они открывают локальную игру.

Из терминала в корне проекта тот же режим запускается двумя командами.

```sh
npm run build
code --extensionDevelopmentPath=./packages/vscode-extension
```

## Сетевая партия

1. Запустите в корне проекта игровой сервер.

   ```sh
   npm run server -- --allow-no-origin
   ```

   Для игры с другого компьютера в LAN добавьте `--host 0.0.0.0`.
2. В пользовательских настройках VS Code укажите `officeWorms.serverAddress`.
   По умолчанию это `ws://127.0.0.1:4180/ws`. Для удалённого сервера используйте его LAN-адрес.
   Если настройку изменили во время игры, новый адрес будет использован при следующем подключении.
3. Откройте **Office Worms: Open Network Game**, введите имя и подключитесь.
   Один игрок создаёт комнату, второй вводит её код. Оба нажимают «Я готов», создатель запускает матч.
   Вторым клиентом могут быть VS Code или [браузер](../../README.md#сетевая-партия).

Закрытие или скрытие панели отпускает удерживаемое направление. Расширение продолжает получать
состояние матча и автоматически переподключается при обрыве. Откройте **Office Worms: Focus Game**,
чтобы вернуться к актуальной карте, HP и очереди. Сервер хранит место 10 минут после разрыва.
Для выхода используйте «Покинуть комнату». Токен восстановления хранится в VS Code SecretStorage.

## Локальная партия

1. Нажмите «Начать ход», затем «Огонь». Начальный выстрел разрушает часть карты, снимает HP и передаёт ход.
2. Выполните **Office Worms: Focus Game** из палитры. Команда переводит фокус на вкладку **Office Worms**.
3. Закройте вкладку и откройте игру снова. Начнётся новая локальная партия с исходной картой и HP.

Локальное состояние существует до выгрузки webview. VS Code может выгрузить его при переключении вкладок.
Стили и JavaScript загружаются из `dist/client` пакета расширения. Для игры достаточно Extension Development Host.
